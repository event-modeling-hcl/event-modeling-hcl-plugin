We run a small dog grooming salon and want an event model. Here is how it works:

"Customers book a grooming slot online. A user can cancel up to 24 hours before. Groomers see the day plan and mark a dog as done. The owner of the salon sets prices, but only the owner. A text message service sends a reminder the evening before each slot. At night a cleanup job removes slots that nobody booked."

Give me the catalog of roles and actors for this model.
